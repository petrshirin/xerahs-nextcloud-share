# Установка

> [!note]
> Понадобятся вход в Nextcloud 16 или новее и папка команды, куда у тебя есть право записи, а для публичных ссылок —
> и право делиться. Чтобы коллеги открывали ссылки «для команды», папка должна быть общей. Для пункта «Ссылка для
> всех» нужна ещё папка, доступная всем пользователям сервера, — её заводит администратор Nextcloud. Подробнее —
> [«Nextcloud» в README](../README.md#nextcloud).

- [macOS](#macos) — одной командой, пара минут
- [Windows (ShareX)](#windows-sharex) — одной командой, пара минут; снимки и запись видео

## macOS

Нужна macOS 12.3 или новее. Ни .NET, ни Homebrew, ни Python не нужны.

### Шаг 1. Запусти установщик

Открой «Терминал» и вставь:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/petrshirin/xerahs-nextcloud-share/main/install-macos.sh)"
```

Установщик спросит две папки в Nextcloud: открой каждую в браузере и вставь адрес из адресной строки, сервер он
возьмёт оттуда же. Можно ввести и путь, например `/Screenshots`: тогда установщик спросит адрес сервера.

- **Папка команды** — для ссылок «для команды» и публичных. Внутри неё nc-share создаст папку `screenshots/` и будет
  класть снимки туда. Папки, которых нет, плагин создаст при первой загрузке.
- **Папка для всех** — по желанию, `Enter` — пропустить. Её видят все пользователи Nextcloud; с ней в меню появляется
  «Ссылка для всех». Внутри nc-share заводит подпапку с твоим логином, у каждого свою.

Если XerahS ещё не стоит, установщик скачает его (около 180 МБ).

### Шаг 2. Разреши запись экрана

Только если XerahS ставился впервые или обновлялся. Сделай первый снимок (`Cmd+Shift+3`): macOS спросит
разрешение на запись экрана и откроет «Конфиденциальность и безопасность» → «Запись экрана и системного звука».
Включи там XerahS и согласись перезапустить программу.

Без разрешения XerahS не снимает и показывает уведомление «Screen Recording permission required».

### Шаг 3. Проверь

1. `Cmd+Shift+4` → выдели область → закончи правку в редакторе → появится меню.
2. Выбери «Ссылка для команды» — цифрой или щелчком. При первой загрузке откроется браузер: войди в Nextcloud и
   подтверди доступ — окно nc-share закроется само, загрузка продолжится. Пароль приложения сохранится в Связке
   ключей, больше вход не спросят.
3. Вставь ссылку из буфера в браузер — откроется файл в Nextcloud. Если задана папка для всех, проверь и «Ссылку для
   всех»: её должен открыть коллега, у которого нет доступа к папке команды.
4. `Cmd+Shift+4` → меню → `1` → вставь в мессенджер: должна вставиться картинка.
5. `Cmd+Shift+4` → меню → `Esc`: ни файла, ни картинки в буфере, ни уведомления.
6. Значок XerahS в строке меню → «File upload» → выбери файл → меню → «Ссылка для команды»: в буфере ссылка на файл.

### Что делает установщик

1. **XerahS 0.33.6**, если его нет или стоит более старый: скачивает с GitHub, сверяет контрольную сумму, кладёт в
   «Программы» и снимает карантин — программа не подписана, и без этого macOS считает её повреждённой. Настройки
   XerahS при обновлении сохраняются. Разрешение на запись экрана сбрасывает: macOS помнит его для прежней сборки,
   и переключатель остаётся включённым, хотя новой сборке снимать нельзя.
2. **Плагин nc-share** из последнего релиза этого репозитория — в `~/Documents/XerahS/Plugins/macos64/ncshare`.
3. **Подключение nc-share** с твоими сервером и папками; сервер проверяет через `status.php` и показывает версию
   Nextcloud. Другие подключения для картинок и файлов предложит убрать: XerahS
   считает их запасными и отправит в них снимок, если в меню выбрать «Скопировать» или `Esc`.
4. **Сценарии XerahS:** `Cmd+Shift+3` — весь экран (снимает системная `screencapture`: полное разрешение Retina,
   без курсора), `Cmd+Shift+4` — область (системное выделение), `Ctrl+Shift+A` — активное окно. После снимка —
   редактор, затем меню nc-share. Своё уведомление и копирование в буфер XerahS не делает — это делает плагин.
   Загрузка файла — пункт «File upload» в меню значка XerahS, затем то же меню nc-share.
   XerahS запускается свёрнутым («Start minimized to tray»): без окна и без значка в Dock, только значок в строке
   меню — через него открываются окно и настройки. Assistant (`Ctrl+Shift+Space`) выключен.
   Если XerahS ещё не запускался, установщик сам создаёт его настройки с этими четырьмя сценариями, и мастер первого
   запуска не появляется. Сам XerahS записывает настройки, только когда мастер пройден до конца, поэтому раньше
   установка без него останавливалась. Сценариев записи видео в XerahS при такой установке нет: видео пишет
   системная панель `Cmd+Shift+5`.
5. **Системные `Cmd+Shift+3` и `Cmd+Shift+4`** выключает, иначе macOS перехватывает их раньше XerahS. Панель
   `Cmd+Shift+5` и `Ctrl+Cmd+Shift+3/4` (системный снимок в буфер) остаются как были.

Перед правкой настройки XerahS и сочетания macOS копируются в `~/Documents/XerahS/nc-share-backup/<дата>`. В конце
установщик печатает команды, которыми всё возвращается как было.

### Если не работает

Лог XerahS — `~/Documents/XerahS/Logs/<год-месяц>/XerahS-<дата>.log`, строки плагина начинаются с `[nc-share]`.

| Симптом | Причина и решение |
|---|---|
| На `Cmd+Shift+4` поверх выделения появляется системное, на рабочем столе файлы «Снимок экрана…» | системные сочетания снова включены — запусти установщик ещё раз или выключи их: «Клавиатура» → «Сочетания клавиш…» → «Снимки экрана» |
| Сочетания не срабатывают, меню не появляется | в логе нет `Discovered plugin: nc-share` — запусти установщик ещё раз |
| В меню пункты ссылок неактивны, «(не настроено)» | не заданы сервер или папка — запусти установщик ещё раз |
| В меню нет «Ссылки для всех» | не задана папка для всех — запусти установщик и вставь её адрес |
| Установщик: «не отвечает как Nextcloud» | неверный адрес сервера, нет сети или VPN. Адрес — то, что в браузере до `/apps/files` |
| Нет значка XerahS в строке меню | его мог спрятать менеджер строки меню (Bartender, Ice, Thaw): перезапусти менеджер и перенеси XerahS в видимые значки. Thaw, например, не замечает значок, если XerahS обновился или перезапустился, пока Thaw работал. Без значка окно XerahS не открыть: щелчок в Dock его не показывает |
| «HTTP 403» | под ним — объяснение сервера. Обычно нет права записи или права делиться в папке, или публичные ссылки запрещены на сервере |
| «HTTP 404» или «HTTP 409» | неверные сервер или папка — запусти установщик и вставь адрес папки заново |
| Публичная ссылка пришла с паролем | сервер требует пароль для публичных ссылок, плагин создал его сам. Без пароля ссылки — только если администратор отключит это требование или исключит твою группу («Общий доступ» → «Exclude groups from password requirements») |
| Срок публичной ссылки короче выбранного | администратор ограничил максимальный срок, плагин сократил срок до предела. Пункты меню меняются `PublicDays` в `SettingsJson` подключения nc-share (`~/Documents/XerahS/Settings/uploader-instances.json`, при закрытом XerahS) |
| Коллега не может открыть ссылку «для команды» | у него нет доступа к папке — нужна общая папка или папка, которой ты поделился. Или отправь «Ссылку для всех» |
| Коллега не может открыть ссылку «для всех» | у него нет доступа к папке для всех — права на неё настраивает администратор Nextcloud |
| «Пароль приложения не подходит» | пароль отозван — при следующей загрузке nc-share попросит войти заново |
| Снимок загрузился, хотя выбран пункт `1` | остались другие подключения — запусти установщик и согласись их убрать |
| Установщик: «XerahS не закрылся» | закрой XerahS через значок в строке меню и запусти установщик ещё раз |

### Обновление

Та же команда из шага 1. Сервер и папки можно оставить — нажми Enter. Если папка для всех ещё не задана (её не было
до версии 0.7), установщик спросит и её; `Enter` — пропустить. Остальные настройки подключения nc-share сохраняются.

### Удаление

1. Выполни команды «Вернуть как было», которые установщик напечатал в конце. Или вручную: удали папку
   `~/Documents/XerahS/Plugins/macos64/ncshare` и включи системные сочетания («Клавиатура» → «Сочетания клавиш…» →
   «Снимки экрана»).
2. Отзови пароль приложения: Nextcloud → «Настройки» → «Безопасность» → `nc-share/… (XerahS)`. Сохранённый вход
   лежит в Связке ключей: записи `XerahS` с учётной записью `ncshare:default:…`.

### Сборка из исходников

Для разработки. Нужен .NET 10 SDK (`brew install --cask dotnet-sdk`) и установленный XerahS:

- `xerahs-plugin/install.sh` — собрать и положить плагин в XerahS (затем перезапустить XerahS);
- `xerahs-plugin/pack.sh` — собрать архив для релиза `dist/nc-share-xerahs.zip`. Установщик со своим архивом:
  `NCSHARE_ZIP=$PWD/dist/nc-share-xerahs.zip ./install-macos.sh`.

## Windows (ShareX)

Нужна Windows 10 или 11. Снимает, записывает видео и редактирует [ShareX](https://getsharex.com), меню и загрузку
делает программа `nc-share.exe` из каталога [`nc-share/`](../nc-share). Ни .NET SDK, ни Python не нужны: если ShareX
нет, установщик поставит его сам, а `nc-share.exe` соберёт компилятором C#, который есть в любой Windows.

### Шаг 1. Запусти установщик

Открой PowerShell (`Win+X` → «Терминал») и вставь:

```powershell
irm https://raw.githubusercontent.com/petrshirin/xerahs-nextcloud-share/main/install-windows.ps1 | iex
```

Установщик спросит две папки в Nextcloud: открой каждую в браузере и вставь адрес из адресной строки, сервер он
возьмёт оттуда же. Можно ввести и путь, например `/Screenshots`: тогда установщик спросит адрес сервера.

- **Папка команды** — для ссылок «для команды» и публичных. Внутри неё nc-share создаст папки `screenshots/` и
  `videos/` и будет класть файлы туда. Папки, которых нет, nc-share создаст при первой загрузке.
- **Папка для всех** — по желанию, `Enter` — пропустить. Её видят все пользователи Nextcloud; с ней в меню появляется
  «Ссылка для всех». Внутри nc-share заводит подпапку с твоим логином, у каждого свою.

Если ShareX ещё не стоит, установщик поставит его через winget — Windows спросит
разрешение. Права администратора больше ни для чего не нужны.

### Шаг 2. Проверь

1. `Ctrl+PrintScreen` → выдели область → редактор → `Enter` (зелёная кнопка «Продолжить») → появится меню. При первом
   снимке ShareX спросит, какой редактор открывать, — подойдёт любой.
2. Нажми `2`. При первой загрузке откроется браузер: войди в Nextcloud и разреши доступ — окошко nc-share в правом
   нижнем углу закроется само, загрузка продолжится. Пароль приложения сохранится зашифрованным, больше вход не спросят.
3. Вставь ссылку из буфера в браузер — откроется файл в Nextcloud.
4. `Ctrl+PrintScreen` → меню → `1` → вставь в мессенджер: должна вставиться картинка.
5. `Shift+PrintScreen` → выдели область → запись пошла → `Shift+PrintScreen` ещё раз — стоп → меню → `3`: публичная
   ссылка на видео. Откроется страница Nextcloud с плеером.

### Сочетания

| Сочетание | Что делает |
|---|---|
| `Ctrl+PrintScreen` | область → редактор → меню |
| `PrintScreen` | весь экран → редактор → меню |
| `Alt+PrintScreen` | активное окно → редактор → меню |
| `Shift+PrintScreen` | запись видео области (MP4); то же сочетание — стоп → меню |
| `Ctrl+Shift+PrintScreen` | запись GIF; то же сочетание — стоп → меню |

Это сочетания ShareX по умолчанию. Если ты их менял, установщик оставит твои и в конце покажет, какие получились.
Поменять — ShareX → «Горячие клавиши…».

В редакторе: `Enter` — дальше, к меню; `Esc` — отмена снимка. Кнопкой загрузки в редакторе не пользуйся: она
отправляет снимок на хостинг из настроек ShareX, мимо меню.

### Видео

Запись экрана ShareX делает сам, ffmpeg у него в комплекте. После остановки записи меню появляется сразу, без
редактора:

- в меню — кадр из видео, длительность и размер;
- `1` копирует запись как файл: она вставляется в мессенджер, письмо или папку;
- остальные пункты — те же ссылки, что для снимков. Публичная ссылка на видео ведёт на страницу Nextcloud со встроенным
  плеером, а не на сам файл, как у картинок (меняется настройкой `FilePublicLinkSuffix`);
- пока видео загружается, кольцо у курсора заполняется по мере отправки;
- файлы ложатся в `<папка команды>/videos/team/2026/10/…`, `…/videos/public/…` и
  `<папка для всех>/<логин>/videos/2026/10/…`. GIF тоже считается записью.

Звук, частота кадров и кодек — ShareX → «Настройки задач…» → «Запись экрана» → «Настройки записи экрана…». Звук по
умолчанию не пишется: выбери источник звука там же.

Снимки и записи остаются на диске в `Документы\ShareX\Screenshots`, как обычно у ShareX: если меню закрыли или
загрузка не удалась, запись не пропадёт.

### Что делает установщик

1. **ShareX**: находит установленный, в том числе из Microsoft Store. Если его нет — ставит через winget, а без
   winget — установщиком с GitHub.
2. **nc-share**: скачивает исходники из этого репозитория, собирает `nc-share.exe` компилятором C# из .NET Framework и
   кладёт в `Документы\ShareX\Tools\nc-share` вместе с `nc-share.ini`. Собранный на месте exe Windows не считает
   скачанным из интернета, SmartScreen его не останавливает. Сервер проверяет через `status.php` и показывает версию
   Nextcloud.
3. **ShareX → «Настройки задач…»**:
   - «Задача» → «После захвата…»: ✅ «Открыть в редакторе изображений», ✅ «Сохранить изображение в файл»,
     ✅ «Выполнить действия». Убирает то, что мешает меню: копирование изображения, файла или пути в буфер (затёрло бы
     ссылку), загрузку на сервер, меню быстрых задач, окна после захвата и перед загрузкой и «Удалить локальный файл»
     (иначе пропадали бы записи);
   - «Действия»: действие `nc-share` — `nc-share.exe` с аргументом `%input`. Другие действия остаются, nc-share
     идёт последним;
   - «Общие»: «Показывать уведомление с предпросмотром…» и «Проиграть звук после выполнения задачи» выключены —
     результат показывает nc-share.

   Сочетания снимков и записи, у которых вместо общих настроек свои, правит так же.
4. **PrintScreen**: в Windows 11 эта клавиша по умолчанию открывает «Ножницы» и ShareX её не получает — установщик
   выключает это («Специальные возможности» → «Клавиатура» → «Использовать кнопку Print Screen…»).
5. **Запуск**: перезапускает ShareX и по его логу проверяет, что сочетания заняты.

Перед правкой настройки ShareX и прежний nc-share копируются в `Документы\ShareX\nc-share-backup\<дата>`. В конце
установщик печатает команду, которой всё возвращается как было.

### Если не работает

Лог nc-share — `%TEMP%\nc-share.log`, лог ShareX — `Документы\ShareX\Logs\ShareX-Log-<год-месяц>.txt`.

| Симптом | Причина и решение |
|---|---|
| `irm`: «Не удалось создать защищённый канал SSL/TLS» | старая Windows 10 без TLS 1.2 по умолчанию: выполни `[Net.ServicePointManager]::SecurityProtocol = 'Tls12'` и повтори команду |
| PrintScreen открывает «Ножницы», ShareX пишет «Hotkey registration failed» | Windows ещё держит клавишу — выйди из Windows и войди снова. Не помогло — выключи вручную: «Параметры» → «Специальные возможности» → «Клавиатура» → «Использовать кнопку Print Screen…» |
| После снимка нет меню, снимок просто сохраняется | действие nc-share выключено или удалено — запусти установщик ещё раз |
| Меню есть, но в буфере не ссылка, а картинка или путь к файлу | в «После захвата» снова включено копирование — запусти установщик ещё раз |
| В меню пункты ссылок «(не настроено)» | не заданы сервер или папка — запусти установщик ещё раз |
| В меню нет «Ссылки для всех» | не задана папка для всех — запусти установщик и вставь её адрес |
| Установщик: «не отвечает как Nextcloud» | неверный адрес сервера, нет сети или VPN. Адрес — то, что в браузере до `/apps/files` |
| «HTTP 403» | нет права записи или права делиться в папке, или публичные ссылки запрещены на сервере |
| «HTTP 404» или «HTTP 409» | неверные сервер или папка — запусти установщик и вставь адрес папки заново |
| Публичная ссылка: ошибка про срок (expiration date) | администратор ограничил максимальный срок ссылки — поменяй `PublicDays` в `nc-share.ini` |
| Коллега не может открыть ссылку «для команды» | у него нет доступа к папке — нужна общая папка или папка, которой ты поделился. Или отправь «Ссылку для всех» |
| Коллега не может открыть ссылку «для всех» | у него нет доступа к папке для всех — права на неё настраивает администратор Nextcloud |
| Окошко входа не закрывается | в браузере не дошли до конца: после входа Nextcloud просит разрешить доступ для `nc-share (ShareX)` — нажми кнопку на этой странице. Закрыл окошко, а доступ разрешил — следующая загрузка в течение 20 минут подхватит вход сама |
| «Пароль приложения не подходит» | пароль отозван — при следующей загрузке nc-share попросит войти заново |
| «Нет связи с … после 3 попыток» | нет сети или VPN; у большого видео — слишком медленная отправка: уменьши частоту кадров или качество в параметрах записи |

### Обновление

Та же команда из шага 1. Сервер и папки можно оставить — нажми Enter. Если папка для всех ещё не задана, установщик
спросит и её; `Enter` — пропустить. Остальные настройки `nc-share.ini` тоже сохраняются, а новые появляются в нём
со значениями по умолчанию.

### Удаление

1. Выполни команду «Вернуть как было», которую установщик напечатал в конце. Или вручную: ShareX → «Настройки
   задач…» → «Действия» → удали `nc-share`, затем удали папку `Документы\ShareX\Tools\nc-share`.
2. Отзови пароль приложения: Nextcloud → «Настройки» → «Безопасность» → `nc-share (ShareX)`. Сохранённый вход лежит
   в `%APPDATA%\nc-share` — удали эту папку.

### Сборка из исходников

Для разработки: установщик собирает `nc-share.exe` из локальных исходников, если указать их папку. Файл установщика —
в UTF-8 без BOM, поэтому Windows PowerShell читает его так:

```powershell
$env:NCSHARE_SRC = "$PWD\nc-share"; iex (Get-Content -Raw -Encoding UTF8 .\install-windows.ps1)
```

Проверить установщик, не трогая ShareX: `NCSHARE_TEST=1` и `NCSHARE_SHAREX_DIR` — папка с копией
`ApplicationConfig.json` и `HotkeysConfig.json`. Остальные переменные описаны в начале
[`install-windows.ps1`](../install-windows.ps1).
